# Refpaw — Competitor synthesis and visual brief

Built from the independent research already completed for the Refpaw project and an additional live-website review in November 2026.

## What Refpaw can learn from competitors

- **My Furry Art** — https://www.myfurryart.com/ : simple service taxonomy, reassurance, customer explanations and prominent CTAs. Borrow its **clarity**, not its visual identity.
- **MyFurryRefSheet** — https://myfurryrefsheet.com/ : deep reference-sheet specialization and clear service hierarchy. Avoid oversized navigation and copy-first pages.
- **Supermint** — https://supermint.co/ : transparent commission types, granular inclusions, explicit artist process, pricing and extras. Refpaw should present quote-based scopes and itemized additions until actual rates are known.
- **VGen** — https://vgen.co/ : artist discovery and a structured request → proposal → invoice experience; reflect this in the Refpaw inquiry flow and future admin work.
- **Artconomy** — https://artconomy.com/ : character-centric discovery and commission handling.
- **Studio Illos by Studio Slatem** — https://www.studioslatem.com/portfolio/illos-branding-illustration : proprietary illustrated icon universe and strong hand-drawn identity. The crucial lesson is to create a consistent visual grammar, not mere pastel panels.
- **Projects Studio** — https://www.projects-studio.com/ : artwork and hand-drawn accents consistently across sections, not merely inside the gallery.
- **Panda Parfait** — https://pandaparfait.co/ : furry community personality and visible art.

## Refpaw's own distinctive system

1. Treat the whole site like a **living character reference sheet**.
2. Use the four paw toe-bean colors as navigational signifiers, not random decoration.
3. Hero artwork must dominate; supersized hand-inked personality anchors typography.
4. A paper-sheet / notebook metaphor connects service modules, artist cards, gallery, and order form.
5. Studio proof must come from real work, real artists and authentic commissioned testimonials only.
6. Keep ordering concise: service → character → extras → contact/review.
7. No invented quotes, review metrics, rates, commission availability or client examples.

## Legitimate non-character art sources to consider

- [Fredoka, SIL Open Font License](https://github.com/google/fonts/tree/main/ofl/fredoka) — headline typography.
- [DM Sans, SIL Open Font License](https://github.com/google/fonts/tree/main/ofl/dmsans) — UI typography.
- [Lucide Icons, ISC](https://github.com/lucide-icons/lucide/blob/main/LICENSE) — optional utility icon language.
- [Fontshare](https://www.fontshare.com/about) — optional additional typefaces; check each family's license.
- [SVG Repo licensing](https://www.svgrepo.com/page/licensing/) — icons with per-asset license checks.
- [Hero Patterns](https://heropatterns.com/) — optional patterns; site's CC BY license requires attribution.

We did **not** copy or adapt copyrighted competitor portfolio illustrations, logos, mascots or screenshots into shipped visual assets. All page illustrations in the prototype originate from original visual concept generation and are **not a substitute for real human-created Refpaw commissioned artwork**.
